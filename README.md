## Projects

### [DailyRugby](https://github.com/Rafa-X9/DailyRugby)

An ASP.NET Core + Discord.Net rugby simulation game.

It is a Discord bot and allows users to create teams, championships, games, tactics, coaches, etc.

Some of the things I've worked on with this project are:

* ASP.NET Core
* Discord.Net slash commands
* SQLite
* Background scheduling
* Game simulation
* Round-robin championships

The main feature of this project's architechture is the separation of simulating the game from telling Discord about the simulation.

---

### [SensoryAnalysis](https://github.com/Rafa-X9/SensoryAnalysis)

An ASP.NET Core project created for an IFRO assignment involving **sensory analysis**.

It implements sensory testing workflows such as:

* Triangle tests
* Duo-trio tests
* Sample generation
* Judges/participants
* Results
* PDF generation

The project uses SQL Server and follows a layered structure with concepts such as services, entities, and strategies.

This project was made to help my group to do an actual sensory analysis for IFRO.
